# 🏠 房产智能选房系统 · HomeMatch Pro

> 覆盖全价格段的房产智能评估与匹配桌面系统
> Full-range Real-Estate Intelligent Evaluation & Matching System

内置 **21,852 套房源 · 192 个真实楼盘 · 24 座城市 · 12 个价格段（37万 ～ 1.6亿）**，支持多维筛选、房源对比、购房成本测算、智能偏好匹配，并可对接 **DeepSeek API** 生成 AI 置业解读与对比报告。

---

## ✨ 功能特性

| 模块 | 能力 |
|---|---|
| **楼盘库浏览** | 24 城 192 个真实楼盘 21,852 套房源；按城市 / 价格段 / 户型 / 风格 / 地段 / 物业费 / 景观 / 楼龄 / 关键词多维筛选，支持排序与分页 |
| **价格段导航** | 12 档价格段一键切换（50万以下 → 1亿以上） |
| **房源详情** | 单价 / 总价 / 户型 / 楼层 / 景观 / 装修 / 楼龄 / 物业 / 学区 / 配套，并给出**首付、月供（30年·3%）、购房税费（契税+中介费）**测算 |
| **同盘房源对比** | 同一楼盘内按"楼栋房号 / 户型 / 楼层 / 景观 / 装修"逐套精细化对比（同盘最多 180+ 套） |
| **对比评估** | 1–4 个楼盘 **15 维横向对比表 + Canvas 雷达图 + 综合评分**（总价/单价/月供/地段/交通/通勤/物业/学区/配套/房龄/绿化/楼层/景观/性价比） |
| **智能匹配** | 预算滑块 + 城市/房型/楼层/景观/风格约束 + **自住/投资双模式** + **偏好画像**（通勤/学区/景观/新盘滑杆自动调整权重）+ 11 维加权评分，输出 TOP10 及推荐理由、维度雷达条 |
| **AI 解读** | 接入 DeepSeek：一键生成多楼盘对比报告、TOP3 置业解读（含议价与风险提示） |
| **偏好记忆** | 预算、城市、模式、画像、权重自动保存到本地，下次打开自动恢复 |

## 📊 数据规模

- **母盘**：192 个真实楼盘（北京、上海、深圳、广州、杭州、成都、南京、苏州、武汉、重庆、西安、天津、合肥、郑州、青岛、长沙、福州、厦门、济南、昆明、宁波、无锡、东莞、佛山）
- **房源**：21,852 套 —— 每盘按 户型 × 楼层 × 景观 × 装修 × 面积系数 生成，并赋予确定性楼栋房号（如 `3幢3单元3001室`）
- **价格**：总价 37 万 ～ 1.6 亿，12 个价格段全覆盖（50万以下 / 50-100万 / … / 5000万-1亿 / 1亿以上）
- **风格**：8 种（新中式 / 现代简约 / 法式 / 欧式 / 美式 / 日式 / 轻奢 / 原木）

> ⚠️ 楼盘均价、物业费、板块信息来源于 58 同城 / 安居客 / 房天下 / 吉屋 / 中指研究院等公开行情（2025–2026 采集），用于演示与评估参考，**不构成任何投资建议**；实际价格以市场实时挂牌为准。

## 🧱 技术架构

```
纯前端数据 + 本地渲染 + DeepSeek 单点 API 代理（无后端服务器 / 无数据库）
```

```
┌─────────────────────────────────────────────────────┐
│  渲染层 (index.html + renderer.js + style.css)       │
│  浏览/筛选/匹配/对比/雷达图/偏好记忆 —— 全部本地计算   │
│  数据: data-cities-part1.js → part2.js → data.js     │
│  （21,852 房源固化为前端静态数据，离线可用）           │
└───────────────────────┬─────────────────────────────┘
                        │ window.deepseekBridge.chat（contextBridge IPC）
┌───────────────────────▼─────────────────────────────┐
│  Electron 主进程 (main.js + preload.js)              │
│  DeepSeek 代理：转发请求 → api.deepseek.com，120s 超时│
│  （避免浏览器跨域、隐藏 API Key）                     │
└─────────────────────────────────────────────────────┘
```

- **离线可用**：不填 API Key，浏览 / 筛选 / 对比 / 匹配全部功能照常；仅"AI 报告"与"AI 置业解读"需要联网。
- **无后端**：没有服务器、数据库、用户系统 —— 单机数据全部在前端。

## 🚀 快速开始

### 方式一：直接运行（无需任何环境）

| 文件 | 说明 |
|---|---|
| `dist\房产智能选房系统 1.0.0.exe` | 便携版，免安装，双击即用 |
| `dist\房产智能选房系统 Setup 1.0.0.exe` | 安装版，可选安装目录，创建桌面快捷方式 |

### 方式二：源码开发运行

```bash
# 1. 安装依赖（国内镜像）
npm install --registry=https://registry.npmmirror.com

# 2. 启动
npm start
```

> 环境要求：Node.js ≥ 16，Windows 10/11（x64）。

## 🔑 DeepSeek 配置（可选）

在应用「对比评估」或「智能匹配」页面的 API Key 输入框填入你的 DeepSeek API Key 后，即可使用：

- **AI 对比报告**：对选中的 2–4 个楼盘生成全面对比评估（性价比 / 自住 / 投资 / 风险 / 推荐排序）
- **AI 置业解读**：对智能匹配 TOP3 生成置业建议（方案对比 / 议价与风险提示 / 购房时机）

Key 仅保存在当前会话输入框，不写入本地文件（桌面版经主进程代理转发，不暴露在渲染层）。

```
房产智能选房系统/
├── main.js                 # Electron 主进程（窗口 + DeepSeek 代理）
├── preload.js              # contextBridge 桥接（暴露 deepseekBridge.chat）

├── style.css               # 样式（浅色金蓝主题）
├── renderer.js             # 全部交互逻辑（筛选/详情/对比/雷达/匹配/AI）
├── smoke.js / smoke2.js    # 无头冒烟 / 交互冒烟测试
├── icon.ico / icon.png     # 应用图标
├── package.json            # 依赖与打包配置
└── dist/                   # 打包产物（便携版 + 安装版）
```
